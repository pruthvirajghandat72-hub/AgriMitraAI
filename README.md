# 🌱 AgriMitra AI – Smart Agriculture Advisory System

### Innovate. Build. Transform.

AgriMitra AI is a C-based Smart Agriculture Advisory System designed to help farmers understand soil conditions, monitor weather parameters, and make better irrigation decisions.

## 🎯 Problem Statement

Farmers often face challenges in understanding soil health, weather conditions, and irrigation requirements. AgriMitra AI aims to provide simple, input-based agricultural recommendations through a user-friendly C program.

## 🚀 Key Features

- **Soil Analysis:** Evaluates soil pH and NPK nutrient values.
- **Soil Condition:** Identifies soil conditions based on pH.
- **Weather Advisory:** Analyzes temperature, rainfall, and humidity.
- **Smart Irrigation:** Classifies soil moisture as Low, Moderate, or High.
- **Agricultural Recommendations:** Provides basic advisory messages based on user inputs.

## 🛠️ Technologies Used

- Programming Language: C
- Compiler: GCC
- Development Environment: Visual Studio Code
- Version Control: Git and GitHub

## ⚙️ How to Run

1. Clone this repository:

   `git clone https://github.com/pruthvirajghandat72-hub/AgriMitraAI.git`

2. Open the project folder.

3. Compile the source code:

   `gcc main.c -o agrimitra`

4. Run the program:

   `./agrimitra`

   On Windows PowerShell:

   `.\agrimitra.exe`
